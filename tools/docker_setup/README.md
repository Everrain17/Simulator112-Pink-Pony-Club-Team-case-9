# Docker Setup

В этой папке находится `setup.bat` для первоначальной настройки серверной части **System112**.

Скрипт выполняет необходимые действия для подготовки окружения:

* проверяет наличие Python и виртуального окружения;
* устанавливает необходимые зависимости;
* проверяет наличие Docker;
* запускает необходимые Docker-контейнеры;
* ожидает готовности PostgreSQL;
* выполняет миграции базы данных.

## Использование

Перед запуском необходимо скопировать `setup.bat` в корень проекта `Simulator112`.

После этого запустите:

`setup.bat`

После завершения настройки файл можно удалить из корня проекта или вернуть обратно в `tools/docker_setup`.

> Этот файл предназначен для первоначальной настройки серверного окружения и не требуется при обычном запуске уже настроенной системы.
