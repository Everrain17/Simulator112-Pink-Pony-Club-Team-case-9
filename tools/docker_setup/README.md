# Docker Setup

В этой папке находятся вспомогательные файлы для первоначальной настройки серверного окружения **System112**.

## Содержимое

* `setup.bat` — первоначальная настройка окружения System112.
* `download_qwen.bat` — загрузка языковой модели Qwen, необходимой для работы системы.

---

## `setup.bat`

Файл выполняет первоначальную настройку серверной части:

* проверяет наличие Python;
* проверяет виртуальное окружение;
* устанавливает необходимые зависимости из `requirements.txt`;
* проверяет наличие Docker;
* запускает PostgreSQL и Redis через Docker;
* ожидает готовности PostgreSQL;
* выполняет миграции базы данных через Alembic.

`setup.bat` необходимо запускать на компьютере, который используется как сервер System112.

После успешного выполнения первоначальная серверная инфраструктура будет готова к работе.

---

## `download_qwen.bat`

`download_qwen.bat` предназначен для загрузки языковой модели **Qwen2.5-14B-Instruct Q4_K_M**, используемой системой System112.

Модель не входит в основной дистрибутив, так как её размер составляет примерно **9 ГБ**.

Скрипт скачивает модель напрямую с **Hugging Face**, поэтому большой файл не требуется включать в ZIP-архив System112.

### Расположение модели

После загрузки файл помещается в:

```text
llama-b8665-bin-win-cuda-13.1-x64/
└── qwen2.5-14b-instruct-q4_k_m.gguf
```

Папка `llama-b8665-bin-win-cuda-13.1-x64` и содержащиеся в ней файлы `llama.cpp` входят в дистрибутив System112 и должны оставаться на месте.

Удаляется из дистрибутива только сама модель `.gguf`.

### Использование

После распаковки System112:

1. Убедитесь, что папка `llama-b8665-bin-win-cuda-13.1-x64` находится в корне проекта.
2. Запустите `download_qwen.bat`.
3. Дождитесь завершения загрузки модели.
4. После успешной загрузки запустите `System112.exe`.

Если модель уже находится в нужной папке, повторная загрузка не выполняется.

При прерывании загрузки `download_qwen.bat` можно запустить повторно. Загрузка будет продолжена с места остановки, если это поддерживается сервером загрузки.

### Требования

Для загрузки модели необходим:

* доступ к интернету;
* Windows 10/11;
* установленный `curl` (обычно входит в стандартную установку современных версий Windows).

Интернет требуется только для первоначальной загрузки модели. После загрузки Qwen модель хранится локально и используется системой без необходимости повторного скачивания.

---

## Обычный порядок установки

Для новой установки System112 рекомендуется следующий порядок:

```text
Распаковать System112
        ↓
Запустить setup.bat
        ↓
Запустить download_qwen.bat
        ↓
Дождаться загрузки Qwen
        ↓
Запустить System112.exe
```

После первоначальной настройки повторно запускать `setup.bat` и `download_qwen.bat` не требуется, если окружение и модель уже установлены.

---

## Важно

Не удаляйте папку:

```text
llama-b8665-bin-win-cuda-13.1-x64
```

Она содержит компоненты `llama.cpp`, необходимые для запуска языковой модели.

Из основного ZIP-дистрибутива исключается только файл:

```text
qwen2.5-14b-instruct-q4_k_m.gguf
```

Модель загружается отдельно после установки системы.
