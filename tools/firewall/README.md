# Firewall

В этой папке находится `firewall.bat` для настройки Windows Firewall.

Скрипт открывает необходимые TCP-порты для работы **System112** по локальной сети:

* `8010` — Python Backend
* `5000` — C# Backend
* `8000` — TTS Server

## Использование

1. Скопируйте `firewall.bat` в корень проекта `Simulator112`.
2. Запустите его **от имени администратора**.
3. После выполнения система будет доступна другим компьютерам в локальной сети.

> Скрипт требуется запускать от имени администратора.
