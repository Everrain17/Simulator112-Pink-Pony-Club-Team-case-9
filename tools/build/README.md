# Build

Эта папка содержит вспомогательные файлы для самостоятельной сборки `.exe` файлов системы **System112**.

Обычному пользователю эти файлы не нужны — готовые `.exe` файлы уже собраны и могут использоваться без повторной компиляции.

## Если нужно собрать `.exe` самостоятельно

1. Откройте папку `tools/build`.
2. Скопируйте **всё содержимое этой папки** в корень проекта `Simulator112`.
3. Убедитесь, что структура проекта соответствует основной структуре `Simulator112`.
4. Запустите нужный `.bat` файл:

   * `build_teacher.bat` — сборка приложения преподавателя.
   * `build_student.bat` — сборка приложения обучаемого.
   * `build_system.bat` — сборка основного приложения `System112`.
5. После завершения сборки созданный `.exe` файл будет находиться в папке `dist`.

После сборки вспомогательные файлы можно удалить из корня проекта или вернуть обратно в `tools/build`.

> Эти файлы хранятся в проекте для воспроизводимости сборки и разработки.
