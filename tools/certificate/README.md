# Установка сертификата System112

Эта папка предназначена для одноразовой установки доверенного сертификата **System112** на компьютеры обучаемых и преподавателей. 

## Содержимое

* `certificate.bat` — установщик сертификата.
* `ca.crt` — корневой сертификат System112.

## Установка

1. Скопируйте папку `certificates` на компьютер обучаемого и преподавателя.

2. Запустите `certificate.bat` **от имени администратора**.

3. Дождитесь сообщения:

   `Сертификат успешно установлен!`

4. После успешной установки папку `certificates` можно удалить.

## После установки

Сертификат сохраняется в хранилище сертификатов Windows. Поэтому удаление файла `ca.crt` после установки **не удаляет сертификат из Windows**.

Повторная установка на этом компьютере не требуется.

## Важно

* `certificate.bat` необходимо запускать с правами администратора.
* Файл `ca.crt` должен находиться рядом с `certificate.bat`.
* Не изменяйте содержимое `ca.crt`.
* Не копируйте в эту папку приватный ключ CA (`ca.key` и аналогичные файлы).

После установки компьютер сможет доверять сертификатам, подписанным **System112 Trainer Local CA**.
