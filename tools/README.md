# Tools

В этой папке находятся вспомогательные инструменты для разработки, настройки и обслуживания **System112**.

## Структура

* `build` — файлы для самостоятельной сборки `.exe` файлов.
* `debug` — вспомогательные файлы для ручного запуска и остановки компонентов системы при отладке.
* `docker_setup` — файл для первоначальной настройки серверного окружения и Docker.
* `firewall` — настройка Windows Firewall для доступа к системе по локальной сети.
* `certificates` — одноразовая установка доверенного сертификата System112 на компьютеры обучаемых.

## Назначение

Эти файлы предназначены в основном для администратора и разработчика.

Они не требуются для обычной работы уже настроенной версии **System112**, за исключением первоначальной установки сертификата на компьютерах обучаемых.

### `build`

Содержит файлы для самостоятельной сборки приложений:

* `System112.exe`
* `System112_Student.exe`
* `System112_Teacher.exe`

Для сборки необходимо временно скопировать содержимое папки `build` в корень проекта `Simulator112`.

### `debug`

Содержит вспомогательные BAT-файлы для ручного запуска и остановки компонентов системы во время разработки и отладки.

### `docker_setup`

Содержит `setup.bat` для первоначальной настройки серверного окружения:

* проверка Python и виртуального окружения;
* установка зависимостей;
* проверка Docker;
* запуск PostgreSQL и Redis;
* ожидание готовности PostgreSQL;
* выполнение миграций базы данных.

### `firewall`

Содержит `firewall.bat` для настройки Windows Firewall.

Открываются следующие TCP-порты:

* `8010` — Python Backend;
* `5000` — C# Backend;
* `8000` — TTS Server.

Файл необходимо запускать от имени администратора.

### `certificates`

Содержит файлы для одноразовой установки корневого сертификата **System112 Trainer Local CA** на компьютерах обучаемых и преподователей.

Для установки:

1. Скопировать папку `certificates` на компьютер обучаемого и преподователя.
2. Запустить `certificate.bat` от имени администратора.
3. Дождаться сообщения об успешной установке.
4. После установки папку можно удалить.

Сертификат сохраняется в хранилище сертификатов Windows, поэтому удаление файла `ca.crt` после установки не отменяет доверие к сертификату.

Повторная установка на этом компьютере не требуется.

---
