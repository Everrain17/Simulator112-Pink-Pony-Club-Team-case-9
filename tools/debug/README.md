# Debug

Эта папка содержит вспомогательные BAT-файлы для ручного запуска и остановки компонентов **System112** во время разработки и отладки.

Обычному пользователю эти файлы не нужны — для обычного запуска системы используется готовый `System112.exe`.

## Если нужно запустить систему вручную для отладки

1. Откройте папку `tools/debug`.
2. Скопируйте **всё содержимое этой папки** в корень проекта `Simulator112`.
3. Запустите `admin-start.bat`.

Скрипт вручную запускает основные компоненты системы:

* Qwen;
* TTS Server;
* C# Backend;
* Admin Tool.

## Остановка системы

Для остановки запущенных компонентов используйте:

`stop.bat`

Он завершает процессы Python, Qwen и C# Backend.

> Эти файлы предназначены для разработки, диагностики и отладки. Для обычной работы системы они не требуются.
