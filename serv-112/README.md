# serv-112

`serv-112` — серверная часть системы **System112**.

В папке находятся Python Backend, административный инструмент, конфигурация серверной части, миграции базы данных и файлы для работы с PostgreSQL и Redis.

## Основные компоненты

* `backend/` — Python Backend на FastAPI.
* `admin_tool/` — интерфейс администратора для управления сервером и системой.
* `alembic/` — миграции базы данных.
* `alembic.ini` — конфигурация Alembic.
* `requirements.txt` — зависимости Python.
* `docker-compose.yml` — конфигурация PostgreSQL и Redis.
* `ip_set.bat` — автоматическая настройка IP-адреса серверного компьютера.

## Docker

Для работы серверной части используются:

* PostgreSQL — база данных;
* Redis — кэш и вспомогательные задачи.

Контейнеры запускаются через `docker-compose.yml`.

На серверном компьютере необходимо установить **Docker Desktop**.

## Первоначальная настройка

Для автоматической настройки окружения используется:

```text
tools/docker_setup/setup.bat
```

Перед запуском необходимо убедиться, что Docker Desktop установлен и запущен.

Скрипт выполняет:

1. проверку Python и виртуального окружения;
2. установку необходимых зависимостей;
3. запуск PostgreSQL и Redis;
4. ожидание готовности PostgreSQL;
5. применение миграций базы данных.

## Настройка IP-адреса

При переносе серверной части на другой компьютер IP-адрес серверного компьютера может измениться.

Чтобы не изменять `config.py` вручную, используется:

```text
ip_set.bat
```

Скрипт автоматически:

1. определяет текущий IPv4-адрес серверного компьютера;
2. находит `admin_tool/config.py`;
3. обновляет значение `SERVER_HOST`;
4. записывает в конфигурацию актуальный IP-адрес.

Например, если новый сервер имеет адрес:

```text
192.168.1.57
```

после запуска `ip_set.bat` в `config.py` будет установлено:

```python
SERVER_HOST: str = _get("SERVER_HOST", "192.168.1.57") or "192.168.1.57"
```

### Перенос на новый серверный компьютер

После копирования `serv-112` на новый сервер необходимо:

1. Установить и запустить Docker Desktop.
2. Запустить:

```text
tools/docker_setup/setup.bat
```

3. Запустить:

```text
ip_set.bat
```

4. После выполнения `ip_set.bat` запустить серверную часть обычным способом.

Повторно изменять IP в исходном коде не требуется.

## Виртуальное окружение

Виртуальное окружение Python создаётся локально и **не хранится в Git-репозитории**.

В готовом дистрибутиве оно может присутствовать для запуска системы без дополнительной установки зависимостей.

## Миграции

Миграции базы данных находятся в:

```text
alembic/
```

Конфигурация находится в:

```text
alembic.ini
```

Для применения миграций используется:

```text
python -m alembic upgrade head
```

Команду необходимо выполнять из папки `serv-112`, где находится `alembic.ini`.

## Логи

Рабочие логи серверной части сохраняются в:

```text
logs/
```

В том числе:

```text
logs/backend.log
logs/backend.pid
```

Эти файлы являются рабочими данными и не должны храниться в Git.

## Запуск

В обычной версии системы сервер запускается автоматически через основной компонент **System112**.

Ручной запуск компонентов используется преимущественно при разработке и отладке.

Подробные инструкции по запуску всей системы находятся в корневом:

```text
README.md
```

## Git

В репозитории сохраняются исходный код, конфигурация, миграции и документация.

Не включаются:

* `.venv/`;
* `logs/`;
* временные файлы;
* `__pycache__/`;
* локальные конфигурации;
* другие автоматически создаваемые файлы.

Готовая сборка системы со всеми необходимыми зависимостями и моделями распространяется отдельно.
