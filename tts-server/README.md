# TTS Server

TTS Server используется системой **System112** для синтеза речи.

## Установка окружения (Перед первым запуском)

Так как тяжелые зависимости Python не включаются в архив, перед первым запуском необходимо создать виртуальное окружение:

1. Убедитесь, что на компьютере установлен Python и добавлен в переменную среды `PATH`.
2. Запустите файл **`setup_env.bat`** в корне папки. 
3. Дождитесь окончания установки всех библиотек из `requirements.txt`.

## Запуск

Перед запуском убедитесь, что основная система System112 запущена или готова к запуску.

Для ручного запуска:

1. Откройте папку `tts-server`.
2. Запустите сервер через командную строку:

```bat
venv\Scripts\activate.bat
python tts_server.py
```

После запуска TTS Server начинает работать на порту **8000**.

## Автоматический запуск

При обычном запуске системы через `System112.exe` TTS Server запускается автоматически.

В этом случае вручную запускать `tts_server.py` не требуется.

## Важно

* Не закрывайте окно TTS Server во время работы системы.
* Не запускайте несколько экземпляров TTS Server одновременно.
* Виртуальное окружение `venv` создается локально с помощью скрипта `setup_env.bat` и использует зависимости из `requirements.txt`.
* Если TTS Server не запускается автоматически, проверьте файл `Logs/tts.log`.

# ParseClassifier

`ParseClassifier` — компонент системы **System112**, отвечающий за обработку и классификацию текстовых данных, полученных в ходе работы системы.

## Запуск

При обычном запуске **System112** компонент не запускается и предназначен только для обработки `.xlsx` файла с классификациями происшествий.

Поместите `ParseClassifier` и `.xlsx` файл в одну папку и запустите `ParseClassifier` из созданного виртуального окружения:

```bat
venv\Scripts\activate.bat
python parse_classifier.py
```

Вручную запускать `ParseClassifier` при обычной работе системы не требуется.

## Структура

В папке должны находиться файлы и зависимости, необходимые для работы классификатора.

Виртуальное окружение создаётся локально через `setup_env.bat` и не хранится в Git-репозитории / не переносится в архиве.

## Для Git-репозитория

Тяжёлые файлы, виртуальные окружения и скомпилированные зависимости не включаются в репозиторий.

В репозитории сохраняется данный `README.md`, чтобы структура проекта и назначение папки оставались понятными.

## Важно

`ParseClassifier` является частью общей инфраструктуры **System112**. Для полноценной работы необходимо использовать полный комплект компонентов системы и соблюдать инструкции из корневого `README.md`.
